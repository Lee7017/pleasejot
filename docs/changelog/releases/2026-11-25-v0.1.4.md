# v0.1.4 · 2026-11-25

<p class="pj-release-subtitle">PleaseJot 0.1.4</p>

## 界面统一

- 所有浮层统一为一套玻璃材质：12px 圆角、38% 黑遮罩 + 3px 模糊；检查更新、清理附件、AI 新手引导、皮肤指南、同步面板、Office 预览、移动笔记弹窗全部对齐。
- 弹窗统一补上进出场动效：遮罩淡入、面板上移 8px + 98% 缩放进场，退场更快；待办任务弹窗的保存、取消、点遮罩、Esc 均有退场动画。
- 输入类控件改为微下沉底色与淡灰焦点环，去掉了纯白块与发白高光；时间、循环规则下拉不再叠出近白底。
- 侧栏元信息抽屉的遮罩覆盖窄轨与底部导航，整屏统一压暗 + 模糊。

## 待办

- 新增左右滑快捷操作：右滑「全部完成 / 部分完成」，左滑「跳过 / 删除」，一次只显示当前操作并带交叉过渡；鼠标按住同样可拖。
- 日历头部重排：年、月可直接输入，双侧箭头按年切换，月切换与「今天」居中；移除标题和关闭按钮。
- 输入框、日期格子、选择器统一为同一套下沉层级。

## 其他

- 笔记仓与待办底部的圆点行支持触摸拖动翻页，触摸判定范围扩大到整条底部栏。
- 设置页每一行悬停铺满卡片宽度；AI 模型页标题与「新手引导 / 新增配置」同一行（移动端同样适用）。
- 移动端底部导航高度收紧，减少空白。
- 渲染模式「活 / 半 / 不 / 死」与文件夹展开图标迁移到资源目录，统一由 `?raw` 内联，保持可着色。
- 修复网页区块再次编辑时多出「在应用内打开」和取消编辑按钮的问题。

## 验证

- 类型检查（原生与 Mock）通过。
