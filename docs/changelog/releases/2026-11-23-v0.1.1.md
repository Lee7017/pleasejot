# v0.1.1 · 2026-11-23

<p class="pj-release-subtitle">PleaseJot 0.1.1</p>

## 分页与导航

- 修复分页吸附先冲过目标页再回弹、快速连续滑动跨首尾后落错页的问题。
- 仓库与待办标题改为交叉淡入，滑动中段不再出现标题空白。
- 鼠标滚轮改为连续跟手：半轮约两页，停手约 90ms 后平滑吸附，不再一格一页、一卡一卡。
- 触摸手势仍保持一次一页，不改变原有操作习惯。

## 待办

- 分页标题栏新增按视图自适应的筛选：时间线支持隐藏已完成、只看逾期；今日应办和无定期支持隐藏已完成；循环历史支持按状态筛选。
- 时间线、今日应办、循环历史和无定期分别记忆筛选状态；循环规划与全部逾期没有可筛选项时，入口保留但置灰。
- 分区图标迁到分页底部圆点，圆点同步皮肤的缩放和透明度。

## 皮肤与文档

- 更新滚轮相关 motion token 语义：`wheel-frequency` 用于推导吸附时长，`follow-ms` 控制跟手平滑。
- 同步皮肤 SDK、Schema、完整样例和导航文档。

## 验证

- 类型检查（原生与 Mock）、导航回归、皮肤回归通过。
- 本次未对正式安装包进行全新 Windows / Android 系统的完整安装与真机业务验收。
