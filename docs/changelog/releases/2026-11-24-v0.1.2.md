# v0.1.2 · 2026-11-24

<p class="pj-release-subtitle">PleaseJot 0.1.2</p>

## 附件与预览

- Office、PDF 附件链接统一显示为文件卡片：类型图标、文件名与文件大小/修改时间，点击即打开预览，卡片可一键删除引用。
- PDF 与 Office 预览统一为单行顶栏：文件名、翻页、缩放与更多菜单，关闭入口固定在右侧。
- PDF 增加页码显示与跳页，渲染清晰度按屏幕像素比提升到 3 倍。
- 修复 PDF 多页时后续页面空白的问题，缩放与翻页不再中断渲染。

## 手写

- 手写预览卡片与网页块统一风格：标题、缩放、重置视图、编辑与删除使用一致的图标按钮。
- 手写编辑弹层改为单行顶栏，取消与完成并排，画布空间更大；`Ctrl/Cmd + Enter` 可直接完成。
- 修复部分手写附件打开编辑器后立即关闭的问题。

## 网页块

- 网页卡片改为铺满内容区，随窗口自适应，不再固定窄宽度。
- 图标与工具栏统一为同一套线性图标与描边。

## 编辑器

- 表格工具改为行列选择器：点选行列后插入对应尺寸的 Markdown 表格。
- 工具栏默认顺序更新；分享与导出合并为一个菜单，提供「复制为富文本」与「导出为压缩包」。
- 插入 Office/PDF 附件后立即显示文件卡片，无需切换页面刷新。

## 设置

- 可点击的版本号与配对码使用常驻虚线提示，悬停加深。
- 设置页下拉控件圆角与其它控件统一。
- 检查更新弹窗精简，前端保持自动更新。

## 同步

- 双向同步流程改为六步：核对清单、危操复核、刷新文件、重置选项等，危险操作单独二次确认。
- 同步进度卡显示步骤、百分比与逐项进度，极快完成时直接提示成功。

## 原生

- 新增 `asset_info` 原生命令，用于读取附件大小与修改时间；原生接口提升至 14，需随本安装包交付。

## 验证

- 类型检查（原生与 Mock）、Rust `cargo check` 通过。
- 本次未对正式安装包进行全新 Windows / Android 系统的完整安装与真机业务验收。
